# Recipes App
A application for managing and organizing cooking recipes.   
This project was created to help users manage their personal collection of cooking recipes in a simple and organized way.
## Overview
Recipes App is a recipe management application with built-in user authentication and authorization,
allowing users to securely manage their personal recipe collections.
## Features
- User registration and login.
- Authorization system for managing personal recipes.
- Store and categorize ingredients.
- Create new recipes.
- View stored recipes.
- Update existing recipes.
- Delete recipes.
- Get recipes calories calculations via OpenAI prompt.
- Easy to expand with new features.
## Tech Stack
### Backend
- FastAPI
- PostgreSQL
### DevOps & Infrastructure
- Docker   
  The entire application stack is containerized with Docker, ensuring consistent development and deployment environments across different systems.
- Docker Compose   
  Used to orchestrate multi-container setups, simplifying the process of running the backend and PostgreSQL services together.
